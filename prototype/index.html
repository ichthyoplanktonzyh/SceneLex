立即体验一次一课 ➔
#01 SCALAR 🎯
标量逼近与临界推拉
almost / barely / exceed
试管注水、悬崖刹车、及格线刻度。标量维度推拉与 100% 临界线逼近。
进入微世界 ➔ GaugeThreshold
#02 DIMENSION 📏
空间几何与极性形变
long / short / fat / thin
1D 长度悬崖搭桥、2D 胖瘦钻铁栅栏。多轴形变与物理任务闭环。
进入微世界 ➔ DimensionalMorpher
#03 SPATIAL 🧭
空间拓扑穿透与轨迹
across / through / along
跨越水面、穿透山体隧道、沿河并行、掠过灯塔。地标维度与包围封闭度。
进入微世界 ➔ SpatialTopologist
#04 PERSPECTIVE 👤
角色视角与动量流向
borrow / lend / buy / sell
第一人称镜头推移：同物理事件下，流出我手 (lend) vs 流入我手 (borrow)。
进入微世界 ➔ PerspectiveFlux
#05 ENTITY ☕
实体范畴与原型变异
cup vs mug / bowl
Labov 原型理论：容量与壁厚滑动，模糊重叠边界与非互斥多选判定。
进入微世界 ➔ ObjectMorphRadar
#06 COGNITIVE 💡
认知更新与线索聚光灯
notice vs realize / discover
外部感官突发捕获 (notice) vs 脑内多线索推理合成顿悟 (realize)。
进入微世界 ➔ EpistemicSpotlight
#07 PHASE 🧊
相变与物理状态演化
melt / freeze / shatter
温控可逆相变 (冰水)、不可逆冲击粉碎 (玻璃)、物质溶解与蒸发。
进入微世界 ➔ PhaseTransition
#08 TEMPORAL ⏱️
双轨时序拓扑轴
until / while / during / since
时间空间化：终点撞墙截断 (until)、双轨并行重叠 (while)、历史锚点延伸。
进入微世界 ➔ TemporalTrack
