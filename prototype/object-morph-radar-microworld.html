为什么旧版的灰色方块 + 特征清单是灾难？
• 旧版让用户看文字清单背诵“器壁厚实、容量较大”，大脑没有形成任何视觉心象。
• 参数化形态微世界让用户亲眼看到杯子变大、变厚、把手变粗的过程，直接在大脑视觉皮层建立原型模板。
ObjectMorphRadar 原语组件的技术架构与 Schema

1. 什么是实体范畴原语？

所有描述器物、服装、工具、家具等实体名词分类的词义，统一由 1 个 参数化形态雷达渲染器 驱动。

2. LLM 编译器入参 Schema

{
  "primitive": "object_morph_radar",
  "category_domain": "drinking_vessels",
  "prototype_target": "mug",
  "parameters": {
    "volume_ml": 450,
    "wall_thickness_mm": 12,
    "handle_style": "sturdy_loop",
    "aspect_ratio": 1.4
  },
  "overlapping_allowed": true,
  "bound_symbol": "mug"
}

3. 破除机械二选一

支持 overlapping_allowed: true。当器物处于两个范畴的重叠带时，判定系统自动认可多选，尊重真实世界的多样性。
