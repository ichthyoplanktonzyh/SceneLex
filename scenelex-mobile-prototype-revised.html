SceneLex 手机端原型

壳沿用不背单词复刻原型，学习内核整体换成「理解词义」流程。内容跑的是正式库真数据：reluctant-01 / messy-01 / almost-01 / dirty-01 及其 21 个场景规格。

两条流程

Learn（首学 · 概念形成） 1 锚点经验 ← 典型经验 2 控制变量 ← 改变非核心变量 3 边界扰动 ← 表面相似、核心不同 4 概念迁移 ← 全新 L1 经验，仍不出现英文 5 符号揭示 ← 英文词第一次正式赋义 6 L2 落地 ← 刚才经验 → 英文表达 → 搭配 Review（复习 · 反向检索） 新 transfer 场景 → 回忆符号 → 揭示 → FSRS 四级评分

关键设计

  • 揭示前不出现任何 L2 标签：目标词和近邻词都不出现，只允许 L1 经验、判断与反馈
  • 四选一被移走：它是符号检索，不是概念形成；反向放进复习（看场景 → 回忆词）
  • 概念迁移放在揭示前：先用全新 L1 情境验证 category 已形成，再把英文符号贴上去；当天稍后测的是符号检索
  • 4 义项一组：一个义项约 90 秒，20 词/组会变成 40 分钟
  • L1 脚手架分三档：复习卡随次数从中文 → 中英混 → 纯英文，对应不背单词的「关闭译文」但有理论依据
  • 概念地图 Tab：直接渲染 relations.boundaries 与 l1_confusables，是竞品没有的资产
