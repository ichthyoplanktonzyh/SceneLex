**mental_state（心理状态型）**不可直接看见，必须通过“可理解的情境张力 + 多条行为证据 + 可观察结果”外化。

核心手法：

* **情境张力**：先建立人物当前愿望、预期或正在进行的活动，再出现与之冲突的要求、机会、信息或现实条件；
* **外化线索组**：使用停顿、视线、姿态、动作启动、动作速度、方向变化、前后行为差和最终结果，让多条证据汇聚；单一表情不构成充分证据；
* **竞争解释控制**：选择不会天然让 fear、anger、sadness、disgust、inability、confusion 或 refusal 成为最强解释的情境；
* **贯穿状态**：如果目标心理状态在行动开始后仍然成立，必须让该状态通过姿态、速度、停顿或动作幅度持续可见，不能只在动作开始前出现；
* **结果校验**：最终发生了什么必须可见。不要只通过旁白或说明宣称人物完成、放弃、接受或拒绝了行动。

场景筛选时优先选择：

* 当前愿望与外部要求之间的冲突一眼可见；
* 心理状态可以通过大尺度身体动作和时间结构表达；
* 不依赖精细面部差异；
* 不依赖复杂手部、餐具、嘴部或小道具交互；
* 可以用少量清楚状态完成“触发 → 反应 → 外化 → 结果”的情境。

五类侧重：

* `prototype`：完整呈现“情境张力 → 多条外化线索 → 可观察结果”，并优先选择语义最纯、最容易进入视频生产的候选；
* `contrast`：在尽量相同的表面情境中，只改变真正的心理诊断轴；两个概念的证据链都必须完整；
* `counterexample`：展示一个常被误读的单一线索，但明确缺少目标心理状态的必要条件，例如动作慢却来自身体疲劳或谨慎操作；
* `boundary`：只改变一个关键变量，展示目标状态何时成立、何时不成立，或另一个词何时更自然；
* `transfer`：更换任务、人物关系或环境，同时保留相同的情境张力和行为外化结构。

陷阱：

* 让人物直接说出自己的心理状态；
* 用一个夸张表情特写替代结构性证据；
* 把行动结果本身当作心理状态的定义；
* 选择天然被另一个强情绪支配的场景，再用大量 `must_avoid` 勉强修补；
* 把低能量抗拒画成愤怒、厌恶或明确拒绝；
* 只展示停顿或动作慢，却没有建立导致该心理状态的情境条件。
