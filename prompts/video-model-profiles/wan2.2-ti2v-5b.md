# wan2.2-ti2v-5b

- 本地 ComfyUI 中的 Wan 2.2 TI2V 5B，可做 T2V 或以一张首帧做 I2V。
- 更适合 3–5 秒、单一主要动作、简单或固定机位的 clip；不要要求一次完成复杂多镜头叙事。
- 简单场景可直接 `direct_t2v`；角色、风格或构图需要稳定时用 `image_guided_i2v`。
- 当教学场景包含明显不同的事件阶段时可用 `split_clips`，但按动作承载能力拆分，不机械照搬 semantic beats。
- I2V 的 `image_prompt` 负责主体、环境、构图、表情和起始状态；`prompt` 主要写主体动作、动作速度、视线/表演变化、相机运动与结束状态。
- 每个 prompt 使用清楚自然的英文，避免一次要求多个相互冲突的动作或大幅时空变化。
