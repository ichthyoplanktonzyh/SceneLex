## M0：核心基础设施 ✅

**状态**：已完成。

**交付物**：

- 词义 Schema (`word-sense.schema.json`) v1.0。
- 场景 Schema (`scene-spec.schema.json`) v1.0。
- 资源包 Schema (`resource-bundle.schema.json`) v1.0。
- LLM 起草管线（draft.py + llm.py，支持四协议）。
- 正式库校验与原子 promote 流程（validate.py）。
- 确定性资源导出（export.py）。
- 仓库工作约束文档（AGENT.md）。
- 项目理论文档（一、先明确系统最终要解决什么问题.md）。

**首轮义项**：`messy-01`、`reluctant-01`、`almost-01` + 草稿 `dirty-01`。

## M1：可验证的纵向实验切片 ⏳

**状态**：进行中。

**目标**：用 6–10 个高价值义项完成"语义规格 → 场景证据 → 可评分任务 → 学习迁移验证 → 资源导出"的完整闭环。

### Phase 1.1：补齐当前义项的场景证据

- [ ] `almost-01` 的五类场景证据（当前只有义项规格）。
- [ ] `dirty-01` 审核并 promote 为正式资源。

### Phase 1.2：扩展义项覆盖

选择 3–5 个新义项，优先覆盖：

- 不同 semantic_type（属性、动作、心理状态、标量/逻辑）。
- 至少 2–3 组中文母语者易混淆的相邻词对。
- 场景能清晰表达、传统翻译难以形成听说直觉的词。

候选池：`look/see/watch/glance`、`almost/barely`、`instead/despite`、`realize/notice/discover`。

### Phase 1.3：制作实验材料

- 为已审核义项准备低成本渲染（连续图片/简单动画/动态漫画）。
- 按 `docs/mvp-evaluation.md` 的三层条件（翻译 / 普通图片 / SceneLex 场景证据）组装实验。
- 确保测试材料未在教学阶段出现。

### Phase 1.4：运行对照实验

按 `docs/mvp-evaluation.md` 的六项测量指标：

- 即时声音—场景匹配正确率。
- 相邻词边界判断（允许重叠与证据不足）。
- 新人物、新对象、新环境中的迁移正确率。
- 一周后保持率。
- 正确作答反应时。
- 开放输出的目标表达自然度。

### Phase 1.5：修订资源

按决策规则迭代：

- 原型理解提高但迁移无提升 → 重写 transfer 证据。
- 迁移提高但相邻词区分无提升 → 检查 boundary/contrast 是否把重叠误写成互斥。
- 只比普通图片略好但成本显著增加 → 减少固定场景数量。
- 某类词持续失败 → 为该 semantic_type 建立专门场景设计方法。

### M1 退出条件

- 至少一组高价值词义在新材料上表现出稳定迁移信号。
- 实验结论可追溯到具体资源版本与实验设计。
- 资源导出流程可被外部消费者复现。
- 有明确的"哪些 semantic_type 的场景设计方法有效/需改进"的判断。

## M2：规模化与自动化 🔒

**进入条件**：M1 实验通过（稳定迁移信号确认）。

**候选方向**：

- 扩展到 30–50 个义项。
- 语义场景编译器（自动化起草 → 审核 → 渲染管线）。
- L1 特定教学路径的批量生成。
- 学习者经验模型与个性化渲染。
- 大规模词义库与对比关系数据库。

**明确不在 M2 承诺内**：

- 高成本影视级视频生产。
- 完整的自适应学习产品。
- 商业化、多用户、云同步。

## 依赖关系

```text
Phase 1.1 (补齐现有) ──→ Phase 1.2 (扩展覆盖) ──→ Phase 1.3 (实验材料)
                                                          ↓
                                                    Phase 1.4 (对照实验)
                                                          ↓
                                                    Phase 1.5 (修订资源)
                                                          ↓
                                                     M1 退出判断
                                                          ↓
                                              M2 gate: 是否规模化
```

Phase 1.1 和 1.2 可部分并行：`dirty-01` 审核可与新义项选取同步推进。

## 后续候选方向（M2+ 探索）

以下方向在 M1 实验通过后按优先级排序，不构成当前承诺：

| 方向 | 触发条件 |
|---|---|
| L1 特定教学路径（zh→en 对比入口） | M1 确认场景证据对相邻词区分有效 |
| 学习者经验模型与个性化渲染 | M1 确认通用场景的迁移存在天花板 |
| 从词扩展到短语、句子和连续语言 | M1 确认单词语义接地成立 |
| 语义场景编译器（自动化管线） | 义项数 ≥ 30，人工审核成为瓶颈 |
| 公开 API 与内容分发 | 有外部消费者需求 |
