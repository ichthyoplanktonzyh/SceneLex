# SceneLex — 项目战略文档

> 最后更新：2026-07-18
> 基于 `AGENT.md`、`README.md`、理论总纲与 `docs/production-workflow.md` 提炼

## 1. 产品愿景

构建一套“场景即释义”的词义语义资源与教学证据系统。核心主张：

> 可验证的词义边界 + 能证明学习迁移的场景证据。

SceneLex 不是某个学习 App 的内部素材目录，也不由某个播放器、课程或模型厂商定义。它是一套可独立发布、版本化和复用的语言资源，媒体生产和学习产品均是其消费者与实现层。

## 2. 核心问题

传统学习路径常是 `L2 声音 → L2 文字 → L1 翻译 → 概念`。SceneLex 要建立：

```text
L2 声音 → 场景与经验 → 概念
```

让学习者理解“在什么经验、状态和关系中会自然使用这个表达”，而不是只记翻译。

## 3. 核心原则

1. **词义，不是词头。** 多义词的不同含义是不同教学单位。
2. **场景是释义媒介。** 目标词必须由经验、关系、动作或结果不可替代地支持。
3. **先经验与声音，后文字。** 目标声音在概念证据成立的恰当时机命名经验。
4. **一个词义需要证据组。** 原型、对比、反例、边界、迁移是教学功能，不是固定媒体数量。
5. **语义骨架与表面渲染解耦。** 人物、地点、风格与模型不能成为词义条件。
6. **生成不等于发布。** 模型审核是可选质量参考；人工 promote 决定正式入库。
7. **相邻概念不必互斥。** 包含、重叠、程度和不同维度必须如实表达。
8. **模型按能力适配。** 厂商、模型、工作流和参数只属于适配与追溯层。
9. **语义优先于审美。** 精美但指向错误概念的素材必须淘汰。

## 4. 权威边界

```text
WordSense + SceneSpec       语义权威
        ↓
Director Prompt             模型适配的内部草稿
        ↓
Generated Media + Manifest  渲染与追溯
```

- **语义层拥有**：词义、条件、概念关系、教学证据、学习任务。
- **Director 层拥有**：生成策略、可直接提交的视频提示词、可选关键图提示词和语义 guardrails。
- **适配层拥有**：模型、ComfyUI workflow、供应商参数、seed、分辨率和候选文件。
- **消费端拥有**：学习者身份、学习记录、UI、播放与课程状态。

`SceneSpec.storyboard` 是语义节拍，不是影视镜头表；语义 beat 与制作镜头不一一对应。

## 5. 媒体交付策略

媒体生产的目标不是默认把所有词义做成固定时长的 3D 短片，而是为语义证据选择最合适的形式：

- 实体、属性、空间关系：单图、对照图或交互；
- 动作与状态变化：短循环或短动画；
- 心理、意图和因果：具有压力—反应—行动的短片；
- 时间、逻辑和话语：事件并置、时间结构或组合表达。

品牌与渲染视觉方向统一为Pixar-style 3D动画。`Pixar-style`作为高信息密度风格锚点，与可观察的造型、材质、灯光、色彩和表演规则一起进入Director/Renderer；不进入WordSense或SceneSpec。

短片时长和镜头数由证据密度决定。原型短片可优先尝试约 10–15 秒、3–4 镜头，但不是产品或 Schema 不变量。

## 6. Director 原则

Director Agent 是核心智能中间层：忠实读取已经设计好的词义场景，再按当前视频能力和统一Pixar-style 3D方向写高质量英文提示词。它不重新设计故事或增加记忆点。默认直接T2V；只有实际需要锁定构图/角色或降低动作复杂度时，才使用关键图I2V或少量拆片。

生成应尽早发生，视频本身也是探索反馈。Director 查看结果并修正最主要的语义偏差；第一版不预先建设复杂 Production Package、独立 Reviewer、状态机或强制 animatic。

本地 ComfyUI 是首个执行后端，不是架构依赖。未来更换云端或本地模型，只需更新轻量 capability profile 和渲染接法。

## 7. 内容状态与发布门

```text
candidate → draft → reviewed → published
```

1. **schema-valid**：结构与仓库不变量通过。
2. **reviewed**：语言、语义、场景和教学质量已有可靠审核结论。
3. **published**：来源与生产过程可追溯，学习任务可评分，所需媒体通过 QC。

“场景即释义”是产品前提，学习对照实验可以用于未来优化，不是发布或规模化前置。

## 8. 当前阶段非目标

- 大规模批量出片或数千义项扩产；
- 在生产契约稳定前实现全自动导演；
- 用更多模型掩盖语义、连续性或镜头设计问题；
- 固定所有词义为同一媒体、时长和镜头数；
- 高成本真人或传统影视工业级制作；
- 完整自适应学习产品、云同步、多用户与商业化；
- 绑定特定LLM、图像模型或视频模型。Pixar-style 3D是已确定的渲染风格方向，不属于模型绑定。
